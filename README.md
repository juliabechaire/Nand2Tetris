# 🖥️ Nand2Tetris

This repository contains my solutions, notes, and implementations developed throughout the **Nand2Tetris** course.

Nand2Tetris ("From NAND to Tetris") is a hands-on computer science course that explores how modern computers work by building an entire computing system from the ground up. Starting with a single **NAND gate**, the course gradually develops digital logic, computer architecture, machine language, virtual machines, compilers, operating systems, and ultimately a working computer capable of running applications.

---

## 🎯 Objectives

- Understand how computers work at every abstraction level.
- Apply concepts of digital logic and computer architecture.
- Build hardware components from basic logic gates.
- Implement system software, including an assembler, virtual machine translator, compiler, and operating system.
- Strengthen problem-solving and low-level programming skills.
